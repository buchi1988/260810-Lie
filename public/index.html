0リー群とは

リー群(Lie group)とは、群であると同時に滑らかな多様体でもある数学的対象です。つまり「掛け算(合成)と逆元がある」という代数的構造と、「連続的に、滑らかに動ける」という幾何的構造を併せ持ちます。

身近な例は回転です。平面の回転全体 SO(2)、空間の回転全体 SO(3) はどちらもリー群です。回転どうしは合成でき(群)、回転角を少しずつ変えられます(多様体)。

リー群 = 群 + 滑らかな多様体(演算も滑らか)

このページでは、数式を追うだけでは掴みにくい「連続な対称性」を、手を動かして体感します。すべての図は操作できます。

1いちばん簡単なリー群 — SO(2)

平面の原点まわりの回転全体を SO(2) と書きます。角度 θ の回転は 2×2 行列で表されます。

R(θ) = ( cos θ −sin θ
  sin θ   cos θ )

スライダーで θ を動かすと、点が回転し、行列の成分が連続的に変わります。回転の全体は円周と同じ形をしています — SO(2) という「群」は、多様体としては円周 S¹ です。

35°

合成 = 角度の足し算

群であることの中身は「合成できる」ことです。SO(2) では合成が単なる角度の足し算になります: R(α)R(β) = R(α+β)。二つの回転を合成してみてください。

50°
−20°

2リー環と指数写像

リー群の単位元(=「何もしない」変換)における接空間をリー環(Lie algebra)と呼びます。曲がった群の上の「まっすぐな近似」で、無限小の変換の空間です。

SO(2) の場合、リー環 𝔰𝔬(2) は 1 次元で、生成元は

J = ( 0 −1
 1   0 ) ,    exp(θJ) = R(θ)

リー環(直線)からリー群(円周)へは指数写像 exp で移ります。下の図で接線上の点をドラッグしてください。まっすぐな線が円周に「巻き付く」様子が見えます。θ と θ+2π が同じ回転に写ること(exp は単射でない)も確かめられます。

120°

接線上の点(上)と、その exp による円周上の像(下)。±360° を超えると一周して重なります。

行列の指数関数はほんとうに回転になるのか

exp は行列でも級数で定義されます:

exp(θJ) = I + θJ + (θJ)²/2! + (θJ)³/3! + ⋯

級数を N 項で打ち切った行列を点 (1, 0) に作用させた結果を描きます。項数を増やすと、点が円周上の正しい回転位置に収束していきます。

3順序が効く — SO(3) の非可換性

空間の回転 SO(3) になると、新しい現象が現れます。回転の順序を入れ替えると結果が変わるのです(非可換)。

左は「x 軸まわり 90° → y 軸まわり 90°」、右は「y 軸まわり 90° → x 軸まわり 90°」。同じ 2 つの回転なのに、最終的な向きが違います。

面の記号(●, ×, +)で向きを追ってください。実行後、2 つの立方体は異なる向きで止まります。

この「入れ替えたときのズレ」を無限小のレベルで測るのが、リー環の括弧積(交換子)です:

[X, Y] = XY − YX ,    𝔰𝔬(3) では [Jx, Jy] = Jz

SO(2) では回転が全部可換なので括弧積はすべて 0 でした。SO(3) の面白さ — ジャイロスコープから角運動量の量子化まで — は、この非可換性から生まれます。

自由に回してみる

ドラッグで立方体を回転させて、SO(3) の元(空間の向き)を直接動かしてみてください。

4一回転しても戻らない — SU(2) と二重被覆

SO(3) には有名な「影武者」がいます。単位四元数のなす群 SU(2) です。SU(2) から SO(3) への 2:1 の写像(二重被覆)があり、SU(2) の元 q と −q は同じ回転を与えます。

z 軸まわりの回転角 θ に対応する SU(2) の元は

q(θ) = cos(θ/2) + sin(θ/2) k

スライダーで θ を 0° から 720° まで動かしてください。回転(左)は 360° で元に戻るのに、SU(2) の元(右)は 360° で −1 になり、720° でようやく 1 に戻ります。

0°

この「一回転では戻らない」性質は数学の遊びではありません。電子などのスピン ½ 粒子の状態は SO(3) ではなく SU(2) で変換され、360° 回すと状態ベクトルの符号が反転します。リー群の大域的な形(トポロジー)が、物理の観測に顔を出す例です。
